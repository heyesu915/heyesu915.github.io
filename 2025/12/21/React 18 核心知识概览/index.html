React 18 核心知识概览

模块 核心概念/语法 关键点/变更 适用场景
核心语法 JSX语法 类似HTML的JavaScript语法扩展，需用{}嵌入表达式。 定义组件的UI结构。
组件类型 函数组件（主推）和类组件。 构建可复用的UI单元。
新渲染API ReactDOM.createRoot(...).render(...)替代旧的 ReactDOM.render(...)。 应用入口，启用并发特性。
组件通信与插槽 父传子 (Props) 父组件通过属性向子组件传递数据（字符串、数字、函数、JSX等）。 数据从父组件流向子组件。
子传父 (回调函数) 父组件传递函数给子组件，子组件调用该函数向父组件传递数据。 子组件通知父组件状态变化。
插槽 (children) 使用特殊的 props.children接收组件开始和标签之间的内容。 创建可复用、内容灵活的容器组件。
跨层级通信 (Context) createContext, Provider, useContext，避免多层逐级传递Props。 多个层级的组件需要共享某些全局状态（如主题、用户信息）。
React Hooks 速成 useState 在函数组件中添加和管理状态。 管理组件的内部状态（如输入值、开关状态）。
useEffect 处理副作用操作（数据获取、订阅、手动操作DOM）。 在组件渲染后执行与渲染结果无关的操作。
useContext 订阅Context的值，简化Context使用。 在组件中获取通过Context传递的全局值。

一、核心语法详解与代码示例

1. JSX 语法要点

-

根节点：JSX必须有且只有一个根元素。可以用<div>包裹，或者用空标签<></>（也叫Fragment）避免添加无意义的DOM节点。

-

JavaScript表达式：在JSX中使用花括号{}可以嵌入任何JavaScript表达式，比如变量、计算、三元运算符等。

-

属性名：有些属性名和HTML不同，例如class要写成className，for要写成htmlFor。样式style需要传入一个对象。

2. 组件定义

React 18主推函数组件，因为它更简洁。

3. 新的渲染入口（React 18重要变更）

这是React 18应用启动的方式，它开启了并发渲染等新特性的大门。

二、组件通信与插槽

组件通信是React应用的血脉，让数据在不同的组件间流动起来。

1. 父组件向子组件传递数据（Props）

父组件通过属性传递，子组件通过函数参数props接收。

2. 子组件向父组件传递数据（回调函数）

本质是父组件传递一个函数给子组件，子组件在适当时机（如按钮点击）调用这个函数，并将数据作为参数传回。

3. 插槽（Slots）：使用 children

children是一个特殊的prop，它代表了组件标签内部的内容。这类似于Vue里的插槽，让组件更加灵活。

三、React Hooks 速成

Hooks让函数组件也能拥有状态和生命周期等能力，是现代React开发的核心。

1. useState- 管理组件状态

用于在函数组件内部定义和修改状态。

2. useEffect- 处理副作用

副作用：指那些与组件渲染结果无关的操作，如数据获取、设置订阅、手动修改DOM等。

3. useContext- 跨组件层传递数据

当需要在一个很深的子组件中使用祖先组件传递的数据时，用Context可以避免一层层手动传递Props的麻烦。

总结与建议

1.

核心基础：理解JSX语法和函数组件的写法，并记住React 18使用ReactDOM.createRoot作为新的渲染入口。

2.

数据流：掌握“父传子”（Props）、“子传父”（回调函数）和“插槽”（children）这三种最基本的组件通信方式。

3.

状态与副作用：学会使用useState管理组件内部数据，使用useEffect处理异步操作等副作用。

4.

跨组件通信：在需要避免“Prop逐层传递”时，使用Context（createContext, Provider, useContext）来优化。
